# Projet réalisé par Gabriel Martineau, Jonathan Evoy et Samuel Gilbert.

Ce projet s'agit d'un jeu en réalité augmentée style Tower Defense et est compatible uniquement avec l'Oculus et le Meta Quest.

## Comment jouer?

Avant d'appuyer sur le bouton Démarrer, placer des tourelles aux emplacements valides sur la carte en appuyant sur leur bouton respectif attaché au controlleur gauche de votre Oculus/Meta Quest.

Appuyer sur Démarrer pour commencer les vagues d'ennemis.

Il y a présentement seulement 2 niveaux pour ce petit jeu. Après avoir complété le deuxième niveau, vous avez gagné.
